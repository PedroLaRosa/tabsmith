# Source map: src/shell_parser.rs (at af1b304)

## Behaviour traps
- Trailing empty token uses an ABSOLUTE offset literal (568-569): `if cmd.children.last().map_or(1, |c| c.end) < cmd.end && text.ends_with(' ')`. This is why cmd(" ")==None but toks("  ")==[""] (spec_table 632-633) and toks("FOO=bar ")==[""]. 'Fixing' it to relative offsets/cmd.start changes results.
- Trailing empty token only for ' ' (569 `text.ends_with(' ')`), never '\t', even though tab splits arguments (381 `s[i] == b' ' || s[i] == b'\t'`).
- Newline is NOT an argument separator in words() (381) but next_word() skips any ASCII whitespace (243 `is_ascii_whitespace`). Do not unify the two whitespace predicates.
- A command with no arguments extends to EOF and is incomplete (397-408: `if has { end } else { self.s.len() }`), so `$()`/empty statements swallow the rest of the buffer and "ls | " yields command text " ".
- Command text includes trailing spaces up to the operator because words() keeps looping over spaces (371-391): `git co && ls -l` first command is (0,7) (test 776); token_offsets asserts text "git  co " after `FOO=1  `.
- Alias loop (42-60): expands only tokens[0], only while `cmd.tokens.len() > 1` (user typed past it), each name once via `used`, empty value breaks (46 `.filter(|v| !v.is_empty())`), failed substitute keeps cmd and the next iteration breaks on `used`. Lookup is by unquoted `text` (45), so `\ls` / `'ls'` also expand. Return `(!cmd.tokens.is_empty()).then_some(cmd)` (61).
- Two different quote strips: current_command strips `'…'` only when BOTH ends present (52-55 `strip_prefix('\'').and_then(|v| v.strip_suffix('\'')).unwrap_or(value)`); parse_aliases strips each end independently (74-75). Merging them into one AliasTable rule changes values like `'abc` or `abc'`, and double-stripping `''q''`.
- parse_aliases (65-80): `text.lines()` swallows `\r\n` (zsh test 897 feeds "g=git\r\n"); `strip_prefix("alias").and_then(|r| r.strip_prefix(char::is_whitespace)).unwrap_or(line)` falls back to the ORIGINAL line ("aliasfoo=bar" → key "aliasfoo"); `split_once(sep)` splits at the FIRST sep so `e='a=b'` works; sep is ' ' only for Fish (66), '=' for bash/zsh/pwsh; empty key or value dropped (77); duplicate keys last-wins via HashMap collect.
- substitute_token (85-119): requires exactly one top-level plain Command (`let [node] = tree.children.as_slice()` + `node.kind != Kind::Command`) so replacements with `|`, `&&`, `;`, a leading `FOO=1` assignment, `{`/`(` return None; `command.text.get(..tok.start)?` uses non-panicking `.get`; `tokens.get(index)?` → None out of range (test 935); final `(new.tokens.len() == command.tokens.len() + diff)` rejects empty replacement (test 934).
- substitute_token raw remapping (108-117): alias-produced tokens take the replaced token's raw via `command.tokens.get(k - diff)?.raw`; in_alias uses strict `<` on both sides with `node.start + t.start/end`, so a zero-width trailing token at alias_end is not 'in alias'. original_text is copied from the input (107), not recomputed — chained expansions (ll→ls -l→ls -G -l) keep "ll ".
- original_text vs text: engine stores `cmd_text: cmd.original_text` (engine.rs:548) for Menu typing comparison (alias-command-text-hides-menu, test 844). Swapping in the expanded `text` changes dropdown visibility.
- Token.raw of the last token flows to ParseResult.raw_last_token (parser.rs:983/996/1007 → 905-947) and then `before.strip_suffix(pr.raw_last_token)` (engine.rs:540) to compute the insertion prefix; raw must be the exact source slice. A word starts AT the escape char (384-385, SPEC D22) so `\ fo` has raw "\\ fo".
- inner() unescape rules (215-240): Word unescapes every esc; Str only before `$ ` " \\ \n` or EOF (`None` → trailing `\` of an open string dropped, 231-232); RawStr/AnsiC/Expansion/CmdSubst/Arith verbatim. Precedence is `Word || (Str && matches!)`. Delimiter strip table (219-223: Str/RawStr (1,1), AnsiC (2,1)); close stripped only when complete (225). The Str escape list hard-codes b'\\' and b'`' regardless of shell.
- Scan vs unescape asymmetry: literal() honours esc for every kind except RawStr (326 `kind != Kind::RawStr`) incl. AnsiC, but inner() leaves AnsiC verbatim → `$'c\'d'` is one token with text `c\'d` (test 712).
- simple_expansion (278-293): terminator set hard-codes backslash `b"\t \n$\\"` (283), not self.esc; `$` + one of `*@?-$0_` is a 2-byte SpecialExp (280; so `$_foo` = `$_`+`foo`); lone `$` before a terminator → None (stays a word char) but `$` at EOF is a 1-byte SimpleExp (284-291; test 751 `echo $`).
- pwsh (200-207, 265, 270): esc is backtick, no backtick substitution, no `$'…'` (so `$'a b` → "$a b", test 946), `\` is a plain char; `''` is NOT an escape and leading `&` acts as an operator (ponytail 190-191). Fish uses bash rules here.
- words(): the terminal check precedes child_at (372 before 375) — required so nested backtick/`)` closes; terms = `&|;\n'"`` + terminal (367-368); `let i = i.min(s.len())` (392) guards a trailing escape skipping past EOF.
- Byte-offset invariant: text() is `&self.src[n.start..n.end]` (211) and panics off char boundaries; literal() `j += 2` and words() `i += 1` on esc can land mid-char but node ends are always ASCII/EOF. multibyte_and_no_panics runs every char prefix × Shell::ALL. Switching to char indices changes Token.start/end (bytes) that substitute_token and parser.rs consume.
- descendant_at (167-175): inclusive end (`index > node.end`), first child that matches wins, deepest Command returned; called with buffer_before_cursor.len().
- Statement grammar (457-504): `|`/`|&` bind tighter than `&&`/`||` via re-association when rhs is a List (499-503); reduce flattens only when rhs.kind == kind; `;`, `&`, `&;` end a statement (489); op() is greedy for two-byte `&; |& && ||` (252), `;;` is two `;`.
- Compound `{`: `}` only counts right after a separator (must_terminate, 506-507, 518, 530), so `{a; b}` is incomplete (test 772); missing terminator marks a statement incomplete except AssignmentList (534-537); AssignmentList always complete=true (454); the command after assignments is appended only if no op follows, the last assignment is complete and end != len (449).
- Assignments only at statement start; assignment_eq is ASCII `[A-Za-z0-9_\[\]]+\+?=` (412-420); empty value is a complete assignment via `children.last().is_none_or(|c| c.complete)` (434, D23); value parsed with terminal Some(b' ') (432).
- cmd_subst/compound/subshell complete only if terminated AND non-empty (308, 479 `term.is_some() && !children.is_empty()`).
- Derives are load-bearing: CommandInfo/Token Clone (parser.rs:1051 `cmd.clone()`), PartialEq+Debug (assert_eq!(cmd(..), None), substitute_token(..)==None); Kind Copy+PartialEq+Debug in tests.

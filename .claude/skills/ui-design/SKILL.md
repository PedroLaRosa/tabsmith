Input: component, page, app, or interface spec. May include purpose, audience, constraints.

**IMPORTANT**: if DESIGN.md exists in the project root

## Design Thinking

Before coding, commit to BOLD direction:

- **Purpose**: problem solved, user.
- **Tone**: pick extreme — brutal minimal, maximalist chaos, retro-futuristic, organic, luxury, playful, editorial, brutalist, art deco, pastel, industrial, etc. Inspire from these; design true to chosen direction.
- **Constraints**: framework, perf, a11y.
- **Differentiation**: one unforgettable thing.

**CRITICAL**: clear concept executed with precision. Bold maximalism = refined minimalism — intentionality > intensity.

Implement working code (HTML/CSS/JS, React, etc.):

- Production-grade, functional
- Visually striking, memorable
- Cohesive POV
- Meticulously refined

## Aesthetics

- **Typography**: distinctive, characterful fonts. No Arial/Inter/Roboto/system. Pair display + refined body.
- **Color**: cohesive palette via CSS vars. Dominant colors + sharp accents > timid evenly-distributed.
- **Motion**: CSS-only for HTML; Motion lib for React when available. High-impact moments — one orchestrated page load w/ staggered reveals (animation-delay) > scattered micro-interactions. Scroll triggers, surprising hovers.
- **Composition**: unexpected layouts, asymmetry, overlap, diagonal flow, grid-breaking. Generous negative space OR controlled density.
- **Backgrounds/details**: atmosphere + depth, not solid colors. Gradient meshes, noise, geometric patterns, layered transparencies, dramatic shadows, decorative borders, custom cursors, grain overlays.

NEVER: overused fonts (Inter, Roboto, Arial, system), cliché schemes (purple gradients on white), predictable layouts, cookie-cutter patterns.

Vary every generation — light/dark, fonts, aesthetics. NEVER converge on common picks (e.g. Space Grotesk).

**IMPORTANT**: match code complexity to vision. Maximalist → elaborate animations/effects. Minimalist → restraint, precision, careful spacing/type/subtleties. Elegance = executing vision well.

Don't hold back. Commit fully to distinctive vision.
